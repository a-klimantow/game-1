# Космонавт-охотник

3D-игра (камера сверху под углом, как Diablo/Hades) по сценарию из `docs/scenario.md`.

## Стек
- Godot 4.7 (стандартная сборка), бинарник: `~/.local/bin/godot`
- GDScript, **только со статическими типами** — нетипизированные объявления и unsafe-доступ в проекте настроены как ошибки
- VS Code + `geequlim.godot-tools`; линт/формат — `gdtoolkit`
- Ассеты: паки Quaternius (CC0) в glTF; бинарники хранятся в Git LFS (`.gitattributes`)

## Структура
- `scenes/` — сцены `.tscn`, `scripts/` — код `.gd`, повторяют друг друга по подпапкам
- `assets/` — модели, текстуры, звуки (только импортируемые форматы, без FBX/Unity-копий)
- `data/` — игровые данные как `Resource` (`.tres`): монстры, заказы, диалоги
- `tests/` — тесты (gdUnit4, когда появится логика), `addons/` — плагины Godot
- Файлы `*.uid` и `*.import` коммитим, папку `.godot/` — нет

## Команды
- Открыть редактор: `godot -e --path .`
- Запустить игру: `godot --path .`
- Проверить, что проект грузится: `godot --headless --path . --quit-after 60`
- Линт и формат: `gdlint scripts/ tests/` и `gdformat scripts/ tests/`

## Правила
- Имена: `snake_case` для файлов, переменных и функций, `PascalCase` для классов и узлов
- Тексты игры — на русском; комментарии в коде короткие, на русском
